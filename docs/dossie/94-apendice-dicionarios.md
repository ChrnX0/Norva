## Apêndice E — Os três dicionários, verbatim

Todo texto que o aplicativo mostra, nos três idiomas. Nenhuma tela guardava uma palavra:
o tipo `Widen<T>` fazia uma chave nova em português quebrar a compilação do inglês e do
espanhol até serem escritas. Isto é o produto falando — reconstruir a redação custa mais
que reconstruir o código.

 * Widens every leaf string to `string` while keeping the shape intact.
 * Without this, `as const` would freeze the Portuguese wording into the type
 * and no translation could ever satisfy it - while a missing key must still be
